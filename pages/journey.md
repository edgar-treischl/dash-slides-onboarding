# User Journey

- Während eine Persona beschreibt, wer ein Nutzer ist, beschreibt eine User Journey, wie dieser Nutzer ein bestimmtes Ziel erreicht.

- Sie stellt den Ablauf aus Sicht des Nutzers dar.

- User Persona: Wer ist unser Nutzer?
- User Journey: Wie erlebt der Nutzer den Weg zu seinem Ziel?
- User Flow: Welche konkreten Schritte und Entscheidungen (Interaktionslogik) durchläuft er innerhalb des Produkts?

- Aus den Personas und Journeys leiten wir konkrete Anforderungen an die App ab.
