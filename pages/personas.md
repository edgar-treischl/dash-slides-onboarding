# User Personas

- User Persona ist ein fiktives, aber möglichst realitätsnahes Profil eines typischen Nutzertyps.

Sie repräsentiert eine Gruppe von Menschen mit ähnlichen:
- Zielen, Bedürfnissen, Problemen
- Erwartungen, Verhaltensweisen, Nutzungskontexten

- Eine Persona ist also nicht einfach eine erfundene Person. Sie ist ein Werkzeug, um Design- und Produktentscheidungen auf tatsächliche Nutzerbedürfnisse auszurichten.

- Personas sollten empirisch entwickelt werden.
